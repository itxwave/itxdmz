# Python
• If you have Python installed: Run this command instead:
    bash
        python -m http.server 8000
    or 
        python -m http.server 3000
    or (macOS)
        python3 -m http.server 3000

• If you use VS Code: Install the extension called Live Server, open your index.html, and click the "Go Live" button at the bottom right of the window.
Once started, open your browser and go to http://localhost:3000 (or http://localhost:8000). The error will completely disappear because the protocol is now HTTP.
